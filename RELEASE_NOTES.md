Nexus 1.0.0

A local Windows game library with automatic installed-game discovery, instant search, favorites, platform filters, duplicate grouping, and game details.

Portable — extract Nexus-1.0.0-portable.zip and open Nexus.exe.
Setup — run Nexus-1.0.0-x64-setup.exe.

Requires Windows 10/11 x64 and Microsoft Edge WebView2.
Setup installs for the current Windows user. The portable uses Windows app-data storage.

Discovery uses local records and saved history. Complete never-installed account libraries require additional provider authorization and are outside this release. Original clients handle downloads, DRM, and updates. These Windows binaries are unsigned.

Source, detailed documentation, limitations, and third-party notices:
https://github.com/scntz/nexus

SHA-256 checksums are provided with the release.
