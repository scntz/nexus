# Nexus

A lightweight Windows game launcher built with Rust, Tauri, and Preact. Bring installed Steam, Epic Games, and other supported Windows games into one fast library.

[Download Nexus 1.0.0](https://github.com/scntz/nexus/releases/tag/v1.0.0)

- **Portable** — extract the ZIP and open Nexus.exe.
- **Setup** — run the Windows x64 installer.

Instant search, artwork, favorites, platform filters, duplicate grouping, game details, and standalone/emulator entries.

Requires Windows 10/11 x64 and Microsoft Edge WebView2. Discovery uses local installation records and saved history. Complete never-installed account libraries are outside the zero-setup integration.
